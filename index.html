01 / 基礎

CSS Transition

クラスの付け替えだけで動かす最も手軽な方法。JSはトリガーに徹し、動きの中身はCSSに書く。

.box{transition:left .6s ease,transform .6s}.on .box{left:calc(100% - 60px);transform:translateY(-50%) rotate(180deg)}
el.classList.toggle('on');
02 / 基礎

@keyframes アニメーション

繰り返しや複数ステップの動きはCSS側に任せる。JSは開始/停止の制御だけ。

@keyframes floatY{0%,100%{transform:translateY(-50%)}50%{transform:translateY(calc(-50% - 22px))}}
.box{animation:floatY 1.8s ease-in-out infinite}
03 / 基礎

requestAnimationFrame

フレーム毎に数値を計算したいときに使う自前ループ。

let x=0,dir=1;
function loop(){x+=dir*3;if(x>maxX||x<0)dir*=-1;box.style.left=x+'px';requestAnimationFrame(loop)}
04 / 基礎

Web Animations API

CSSを書かずJSだけでキーフレーム定義。Promiseで完了検知でき、一時停止・逆再生も可能。

box.animate([{transform:'translateX(0) rotate(0deg)'},{transform:`translateX(${dist}px) rotate(360deg)`}],{duration:900,easing:'ease-in-out',fill:'forwards'});
05 / 基礎

イージング比較

同じ距離・同じ時間でもイージング関数で体感速度は大きく変わる。

linear / ease-out / cubic-bezier(.68,-.55,.27,1.55)
06 / 基礎

Penner系イージング関数

CSSのcubic-bezierでは表現しづらい、跳ねる・振動する動きを数式で計算する。

function easeOutBounce(t){const n1=7.5625,d1=2.75;if(t<1/d1)return n1*t*t;if(t<2/d1)return n1*(t-=1.5/d1)*t+.75;if(t<2.5/d1)return n1*(t-=2.25/d1)*t+.9375;return n1*(t-=2.625/d1)*t+.984375}
07 / 物理演算

重力バウンド

速度・重力加速度・反発係数を毎フレーム更新。

vy+=gravity;y+=vy;if(y>floorY){y=floorY;vy*=-bounce}
08 / 物理演算

スプリング（バネ）モーション

目標値との差分に応じて加速するバネのシミュレーション。

const force=(target-pos)*stiffness;vel=(vel+force)*damping;pos+=vel
09 / 物理演算

慣性減速（フリック）

速度を保持し、摩擦係数で徐々に減速させる。

x+=vx;vx*=friction;if(Math.abs(vx)>.3)requestAnimationFrame(inertia)

const dx=(e.clientX-r.left-r.width/2)*.3;const dy=(e.clientY-r.top-r.height/2)*.3;btn.style.transform=`translate(${dx}px,${dy}px)`;

13 / インタラクション

3Dチルト

マウス位置からrotateX/Yを計算し、カードを立体的に傾ける。

const rx=(py-.5)*-20,ry=(px-.5)*20;card.style.transform=`rotateX(${rx}deg) rotateY(${ry}deg)`;
14 / スクロール連動

IntersectionObserver

要素が画面内に入った瞬間を検知してクラスを付与。

この枠が表示領域に入ると発火
new IntersectionObserver(entries=>{entries.forEach(e=>{if(e.isIntersecting)e.target.classList.add('in')})},{threshold:.3})
15 / スクロール連動

スクロール進捗バー

ページ全体の読了率を最上部の緑バーに反映。

const pct=h.scrollTop/(h.scrollHeight-h.clientHeight)*100;bar.style.width=pct+'%';
16 / スクロール連動

パララックス

スクロール量に係数をかけ、背景と前景を異なる速度で動かす。

スクロールでゆっくり動くデモ
layer.style.transform=`translateY(${window.scrollY*.08}px)`;
17 / スクロール連動

スタガー表示

要素ごとに遅延をずらして順番に表示。

el.style.transitionDelay=(i*90)+'ms';el.classList.add('in');
18 / スクロール連動

24 / その他技法

FLIP法
