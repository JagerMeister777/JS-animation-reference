CSS Transition

クラスの付け替えだけで動かす最も手軽な方法。 JSはトリガーに徹し、動きの中身はCSSに書きます。

02

@keyframes アニメーション

繰り返しや複数ステップの動きはCSS側に任せます。 JSは開始・停止の制御だけにできます。

主要コード 
@keyframes floatY {
    0%, 100% {
        transform:
            translateY(15px);
    }
    50% {
        transform:
            translateY(-25px);
    }
}
.box {
    animation:
        floatY
        1.8s
        ease-in-out
        infinite;
}
変更ポイント： 1.8s → 速度。 -25px → 上方向への移動量。 infinite → 繰り返し回数。 50% → 動きの中間地点。

慣性減速（フリック）

ボックスをドラッグして弾いてください
主要コード 
x += vx;
vx *= friction;

    Math.abs(vx) > .3
) {
    requestAnimationFrame(inertia);
}
変更ポイント： frictionを1に近づけると長く滑ります。 小さくするとすぐ止まります。

14

IntersectionObserver

要素が画面内に入った瞬間を検知してクラスを付与します。

この枠が表示領域に入ると発火
主要コード 
new IntersectionObserver(
    entries => {
        entries.forEach(e => {
            if (
                e.isIntersecting
            ) {
                e.target
                    .classList
                    .add('in');
            }
        });
    },
    {
        threshold: .3
    }
);
変更ポイント： threshold: .3を変更すると、要素の何％が見えたら発火するかを変更できます。
15

スクロール進捗バー

ページ全体の読了率を最上部の緑バーに反映します。

ページ最上部の緑色のバーが、このページ全体のスクロール進捗です。
主要コード 
const pct =
    h.scrollTop /
    (h.scrollHeight -
     h.clientHeight)
    * 100;
bar.style.width =
    pct + '%';

prefers-reduced-motion

OS側で視差効果やアニメーションを減らす設定をしているユーザーには、過剰なモーションを抑制します。

主要コード 
@media (
    prefers-reduced-motion: reduce
) {
    * {
        animation-duration:
            .01ms !important;
        transition-duration:
            .01ms !important;
    }
}
アクセシビリティ上の重要ポイントです。 アニメーションを使う場合、ユーザー側の「動きを減らしたい」という設定を尊重できるようにしておくと安全です。
